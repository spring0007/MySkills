# 汉字字典数据库(SQL)

> ## 【本工程内的用途】
>
> 本目录是**源数据归档**，不参与打包。Android 侧读取的是转换后的 SQLite 文件
> `app/src/main/assets/xinhuazidian/xinhuazidian.db`。
>
> 这里的 `xinhuazidian.sql` / `xinhuazidian.mdb` 曾经放在 `assets/` 下，会让 APK
> 凭空多出约 10MB（SQL 压缩后仍有 10.6MB），因此移到了这里。
> **请勿把它们放回 `assets/`。**
>
> ### 重新生成 .db
>
> ```bash
> python tools/sql_to_sqlite.py
> ```
>
> 输入默认是本目录的 `xinhuazidian.sql`，输出默认到 `assets/xinhuazidian/xinhuazidian.db`。
> 脚本结束时会打印 **行数 / 字节数 / sha256**：
>
> - **行数**必须等于脚本内的 `EXPECTED_ROWS`（20822），不等会直接报错退出；
> - **字节数**必须同步到 `AssetDbInstaller.DB_SIZE_BYTES`，否则 App 会把新库
>   当成残缺文件反复重删重拷（这是本地副本完整性的唯一判据）；
> - 改了表结构时，把脚本的 `DB_VERSION` 和 `AssetDbInstaller.DB_VERSION` 一起 +1，
>   版本号写在文件名里，旧文件会在下次启动时被自动清理。
>
> 参考值（DB_VERSION=1）：
>
> ```
> 导入 20822 行，跳过 1 行
> 字节数: 24334336
> sha256: 61f85d0919f381c73a6d29ba31a83d132a41a519138a40c0e87052e05942718c
> ```
>
> 唯一被跳过的是 `zi` 为「牙合」的那条（源数据自带的占位记录，注释写明
> 「简体中文没有收录这个字」）——两个字无法作为单字查询主键。
>
> ### .mdb 是什么
>
> 同名的 Access 版本（2010 年），仅作历史留存参考。Android 无原生 Access 支持，
> 引 Jackcess 也跑不通（它依赖 `java.awt`），**不要试图直接读它**。

## 简介

本仓库提供了一个包含20823个中文单字的汉字字典数据库文件，格式为SQL。该数据库详细记录了每个汉字的拼音、五笔、部首、笔画、笔顺、释义、详解、说文等信息，为中文学习、研究及开发提供了丰富的数据支持。

## 数据库内容

- **拼音**：每个汉字的拼音标注，方便发音学习。
- **五笔**：每个汉字的五笔输入法编码，便于使用五笔输入法进行输入。
- **部首**：每个汉字的部首信息，有助于理解汉字的结构和分类。
- **笔画**：每个汉字的笔画数，帮助掌握汉字的书写顺序和规范。
- **笔顺**：每个汉字的笔顺信息，指导正确的书写顺序。
- **释义**：每个汉字的基本释义，简明扼要地解释汉字的意义。
- **详解**：每个汉字的详细解释，包括字源、演变、用法等。
- **说文**：每个汉字在《说文解字》中的解释，提供更深层次的字义理解。

## 使用方法

1. **下载文件**：点击仓库中的SQL文件进行下载。
2. **导入数据库**：将下载的SQL文件导入到你的数据库管理系统中（如MySQL、PostgreSQL等）。
3. **查询使用**：通过SQL语句查询所需汉字的信息，进行学习或开发使用。

## 适用场景

- **中文学习**：帮助学习者掌握汉字的拼音、笔画、笔顺等基础知识。
- **输入法开发**：为五笔输入法等提供基础数据支持。
- **字典应用**：开发汉字字典类应用，提供详细的汉字查询功能。
- **学术研究**：为汉字研究提供数据支持，帮助分析汉字的演变和结构。
